# Modification notice

DevilTouch is an unofficial, modified distribution workflow built on [DevilutionX](https://github.com/diasurgical/DevilutionX). The pinned maintained DevilutionX fork contains the existing iPad-specific touch and import changes as ordinary source commits. The historical engine patch files are retained for comparison only. Two hash-verified dependency package patches preserve existing Apple compiler compatibility.
